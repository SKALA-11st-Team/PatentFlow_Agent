# Valuation Legal Axis Prompt

권리성 축을 평가한다.

권리성 총점은 100점이며, 반드시 아래 4개 하위 항목 점수를 합산한다.

1. 권리안정성: 30점
2. 청구항 보호력: 30점
3. 권리행사·제품대응성: 25점
4. 포트폴리오·방어가치: 15점

평가 목표:
- 현재 등록된 최종 청구항과 등록상태를 기준으로 권리가 안정적으로 유지될 가능성을 평가한다.
- 최종 독립항과 종속항이 핵심 기술을 얼마나 적절히 보호하는지 평가한다.
- 최종 청구항과 제품/서비스 기능의 대응성 및 침해 발견·입증 가능성을 평가한다.
- 패밀리, 해외 등록 B 문헌, 사내 유사 특허, sibling 특허, 경쟁사 유사 특허가 방어 자산으로 의미가 있는지 평가한다.
- 무효 가능성, 침해 가능성, 분쟁 가능성은 법적 결론으로 단정하지 않는다.

사용 근거:
- 등록상태
- 최종 등록 청구항 전체
- 대표 독립항
- 독립항/종속항 구조
- 현재 유효 청구항 수와 claim_stats
- 발명의 효과와 summary_result
- prior_art_candidates
- citation_evidence.kr_citation_documents: 대상 특허가 인용한 국내 선행문헌의 KIPRIS 상세조회 결과
- citation_evidence.kr_citing_documents: 대상 특허를 인용한 국내 후행문헌의 KIPRIS 상세조회 결과
- citation_evidence.foreign_claim_lookup_candidates: 해외 인용문헌 청구항 조회 후보. 청구항 전문이 없으면 문헌번호 후보로만 취급한다.
- 패밀리 특허 정보
- 해외 등록 B 문헌 여부
- portfolio_context 및 sibling 특허
- 사내 유사 특허 또는 경쟁사 유사 특허가 있으면 참고
- 관련 제품/서비스 정보, related_product, 공개 제품 설명, 내부 제품 대응표가 있으면 참고
- IPC/CPC
- 잔여 존속기간 정보가 있으면 참고

기본 제외 근거:
- 삭제 청구항
- 보정 전 청구항
- 의견제출통지서
- 거절결정서
- 등록결정서
- 심사 중간서류
- 심사이력·보정이력·파일랩퍼 전문

위 제외 근거는 기본 평가 대상이 아니다. 입력에 심사이력 정보가 없더라도 이를 필수 누락으로 보지 않는다.

## 1. 권리안정성 - 30점

목적:
- 현재 등록된 권리가 무효 리스크 없이 유지될 가능성을 평가한다.

평가 원칙:
- 권리안정성은 현재 등록된 최종 청구항과 등록상태를 기준으로 평가한다.
- 삭제 청구항, 보정 전 청구항, 심사 중간 이력은 기본 평가 대상에서 제외한다.
- 입력에 심사이력 정보가 없더라도 이를 필수 누락으로 보지 않는다.
- 다만 선행기술/인용문헌 정보가 부족하면 안정성 판단의 confidence를 낮춘다.
- prior_art_candidates 또는 citation/prior_art evidence가 제공되면 참고하되, 후보 문헌만으로 무효 가능성을 단정하지 않는다.
- citation_evidence에 국내 인용/피인용 문헌의 title, abstract, representative_claims가 있으면 대표 청구항의 핵심 구성과 비교해 신규성/진보성 리스크를 판단한다.
- foreign_claim_lookup_candidates는 해외 문헌 청구항 조회가 필요한 후보 목록이다. 실제 청구항 텍스트가 없으면 직접 충돌 근거로 단정하지 않는다.

점수화:
- 30점: 현재 등록상태가 유효하고, 최종 청구항 기준 핵심 차별점이 명확하며, 유사 선행기술/인용문헌 리스크가 낮고, 패밀리 등록 또는 유지 정보가 긍정적임.
- 20점: 등록상태는 유효하나 유사 선행기술 또는 유사 특허가 일부 있고, 최종 청구항의 차별점은 존재함.
- 5점: 최종 청구항이 유사 선행기술과 매우 가깝거나, 핵심 차별성이 약해 무효 리스크가 높아 보임.
- 0점: 등록상태 또는 최종 청구항 정보가 없어 판단 불가.

점수 예시:
- 등록상태가 등록/유지이고 대표 독립항의 핵심 구성 차별점이 설명 가능하며 표준화 인용문헌이 적거나 직접 충돌 근거가 없으면 30점에 가깝게 평가한다.
- 등록상태는 유효하지만 CN/JP/KR 유사 인용문헌이 여러 건 있고, 차별점은 있으나 구체 비교가 제한되면 20점을 부여한다.
- 대표 독립항의 핵심 구성이 인용문헌 후보와 거의 동일해 보이거나 차별점 설명이 빈약하면 5점을 부여한다.
- 등록상태 또는 최종 청구항 텍스트가 없으면 0점을 부여한다.

## 2. 청구항 보호력 - 30점

목적:
- 최종 청구항이 핵심 기술을 충분히 보호하고, 경쟁사가 쉽게 회피설계하기 어려운지 평가한다.

평가 원칙:
- 청구항 보호력은 현재 등록된 최종 독립항과 종속항을 기준으로 평가한다.
- 삭제 청구항은 존재하지 않는 청구항으로 간주하고 평가하지 않는다.
- 청구항 수만으로 보호력을 판단하지 말고, 독립항이 핵심 기술을 얼마나 포괄하는지 평가한다.
- 불필요하게 좁은 구현 조건, 특정 장치/순서/파라미터에 과도하게 묶인 표현이 있는지 확인한다.
- “권리범위가 넓다/좁다”는 표현은 청구항 근거가 있을 때만 사용한다.

점수화:
- 30점: 최종 독립항이 핵심 기술을 적절히 포괄하고, 불필요한 구현 한정이 적고, 경쟁사가 쉽게 회피하기 어려움.
- 20점: 핵심 기능은 보호하지만, 일부 구성요소가 특정 구현 방식에 묶여 있어 회피 여지가 있음.
- 5점: 청구항이 좁고, 특정 구현 방식에 강하게 한정되어, 회피설계가 쉬움.
- 0점: 최종 청구항 정보가 없어 판단 불가.

점수 예시:
- 대표 독립항이 핵심 데이터 흐름, 제어 로직, 장치 구성 또는 처리 기능을 포괄적으로 잡고 종속항이 보완하면 30점을 부여한다.
- 핵심 기능은 청구하지만 특정 모델, 특정 입력 형식, 특정 처리 순서 같은 구현 한정이 일부 강하면 20점을 부여한다.
- 특정 UI, 특정 파라미터, 특정 장치 조합에만 권리가 묶여 경쟁사가 다른 방식으로 쉽게 구현 가능하면 5점을 부여한다.
- 청구항 텍스트가 없으면 0점을 부여한다.

## 3. 권리행사·제품대응성 - 25점

목적:
- 특허가 실제 제품·서비스에 적용되거나, 침해 발생 시 발견·입증이 가능한지 평가한다.

평가 원칙:
- 권리행사·제품대응성은 현재 등록 청구항과 제품/서비스 기능의 대응성을 기준으로 평가한다.
- 내부 제품 대응표나 명확한 공개 제품 정보가 없으면 제품 적용을 단정하지 않는다.
- 제품 관련 근거가 간접적이면 15점 초과를 피한다.
- summary_result, related_product, 공개 제품/서비스 설명, portfolio_context를 함께 보되 청구항 구성요소와 제품 기능의 직접 대응 여부를 우선한다.
- 내부 구현 중심이라 외부에서 침해 확인이 어려운 경우 낮게 평가한다.

점수화:
- 25점: 최종 청구항 구성요소가 현재 제품/서비스 기능과 직접 대응되고, 해당 기능이 핵심 기능이며, 침해 발견·입증 가능성이 높음.
- 15점: 제품/서비스 적용 가능성은 있으나, 직접 대응 근거가 제한적임.
- 5점: 제품 관련성이 약하거나, 내부 구현 중심이라 외부 침해 확인이 어려움.
- 0점: 제품/서비스 정보가 없어 판단 불가.

점수 예시:
- related_product 또는 공개 제품 설명이 청구항의 핵심 구성요소와 직접 맞고, 외부 화면/API/동작에서 침해 정황을 확인할 수 있으면 25점을 부여한다.
- 제품군이나 사업영역은 맞지만 청구항 구성요소와 제품 기능의 1:1 대응 근거가 부족하면 15점을 부여한다.
- 기술은 내부 알고리즘/운영 로직 중심이고 외부에서 확인하기 어렵거나 제품 관련성이 약하면 5점을 부여한다.
- 제품/서비스 정보가 전혀 없으면 0점을 부여한다.

## 4. 포트폴리오·방어가치 - 15점

목적:
- 단독 권리뿐 아니라 패밀리, 사내 특허군, 경쟁사 대응, 매각·라이선스 관점에서 활용 가능한지 평가한다.

평가 원칙:
- 포트폴리오·방어가치는 심사이력이 아니라 패밀리, 사내 유사 특허, 경쟁사 유사 특허, 잔여 존속기간을 중심으로 평가한다.
- 사내 유사 특허가 있다는 사실만으로 높은 점수를 주지 말고, 보완 관계인지 중복 관계인지 구분한다.
- sibling 특허들이 전후 공정, 보완 기능, 제어 계층, 장치 구성요소를 나누어 보호하는 경우 대상 특허 단독의 권리 한계를 보완하는지 판단한다.
- sibling 특허 사이에 실질적 중복이 크면 유지 우선순위를 낮추는 리스크로, 서로 다른 구성요소를 보호하면 포트폴리오 시너지로 반영한다.

점수화:
- 15점: 패밀리/해외 등록 특허가 있고, 사내 유사 특허와 보완 관계이며, 경쟁사 대응 또는 방어 자산으로 의미가 큼.
- 5점: 관련 특허군이 일부 있으나, 보완 관계나 방어가치가 제한적임.
- 1점: 사내 유사 특허와 중복 가능성이 높거나, 포트폴리오 기여도가 낮음.
- 0점: 패밀리/사내 유사/경쟁사 정보가 없어 판단 불가.

점수 예시:
- 해외 B 문헌 또는 유지 중인 패밀리가 있고 sibling 특허들이 서로 다른 기능을 나누어 보호하면 15점을 부여한다.
- 패밀리 또는 사내 유사 특허는 있으나 보완 관계가 명확하지 않거나 단순 제품군 유사성에 그치면 5점을 부여한다.
- sibling 특허와 권리범위가 거의 중복되어 대상 특허의 추가 기여가 작으면 1점을 부여한다.
- 패밀리, 사내 유사, 경쟁사 유사 정보가 모두 없으면 0점을 부여한다.

## 종합 점수 산정

- score는 반드시 4개 하위 항목 점수의 합계로 산정한다.
- 각 하위 항목은 지정된 점수 후보만 사용한다.
  - 권리안정성: 30, 20, 5, 0
  - 청구항 보호력: 30, 20, 5, 0
  - 권리행사·제품대응성: 25, 15, 5, 0
  - 포트폴리오·방어가치: 15, 5, 1, 0
- 전체 score가 80점 이상이면 grade는 A, 60점 이상이면 B, 40점 이상이면 C, 그 미만이면 D로 둔다.
- confidence는 입력 근거의 충분성에 따라 0.0~1.0으로 산정한다.
- 선행기술/인용문헌 후보가 없다고 낮은 점수를 자동 부여하지 말고, confidence와 missing_information에 보수적으로 반영한다.
- representative_claims 또는 claim_stats가 제공된 경우, 이를 기준으로 권리 구조를 판단하고 “청구항 전문 부재”를 반복하지 않는다.
- representative_claims와 claim_stats가 모두 부족할 때만 청구항 정보 부족을 missing_information에 남긴다.

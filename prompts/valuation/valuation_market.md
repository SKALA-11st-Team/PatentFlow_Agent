# Valuation Market Axis Prompt

시장성 축을 평가한다.

평가 목표:
- 대상 특허가 적용될 수 있는 산업/서비스/기술 영역에서 시장 수요, 도입 움직임, 성장/감소 요인, 경쟁 활동이 확인되는지 평가한다.
- 외부 근거가 대상 특허 기술과 직접 관련되는지, 간접 관련인지 구분한다.

사용 근거:
- news evidence
- industry_report evidence
- company_disclosure
- related_product
- business_area
- technology_area
- portfolio_context

사용할 evidence 필드:
- evidence_id
- title
- source_type
- published_at
- compressed_summary
- key_facts
- related_axes

평가 기준:
- 높은 점수: 뉴스/산업리포트/공시에서 대상 특허의 구체 기능이 독립적으로 필요하거나 관련 제품/서비스의 핵심 기능으로 도입되는 흐름이 명확한 경우
- 중간 점수: 관련 산업 트렌드나 유사 서비스 확산은 확인되지만, 대상 특허의 구체 기능 수요와의 연결이 간접적인 경우
- 낮은 점수: 외부 시장 근거가 부족하거나, 검색된 근거가 넓은 산업 성장만 보여주고 대상 특허의 구체 기능과 약하게만 연결되는 경우

주의:
- portfolio group_size만으로 시장성이 높다고 단정하지 않는다.
- portfolio_context는 동일 제품/공정/서비스를 둘러싼 특허군 형성이 시장 대응 범위를 넓히는지 판단하는 보조 근거로만 사용한다.
- sibling 특허 시너지는 외부 시장 근거와 함께 대상 제품군 또는 공정 자동화 수요를 뒷받침할 때만 시장성에 긍정 반영한다.
- 뉴스/리포트가 시장 일반론에 그치면 confidence를 낮춘다.
- 넓은 산업의 성장성, 투자 확대, AI/자동화 도입 흐름은 대상 특허의 구체 기능 수요를 직접 보여줄 때만 강한 시장 근거로 사용한다.
- 시장 흐름이 대상 특허 기능을 더 큰 플랫폼이나 범용 솔루션에 흡수시키는 방향이면 독립 시장성 리스크로 반영한다.
- 회사가 내부 적용 현황이나 고객 도입 사례를 기사화하지 않는 것은 자연스러우므로, 공개 기사에 직접 도입 사례가 없다는 이유만으로 상용화 가능성을 낮게 단정하지 않는다.
- 검색된 기사에 대상 특허의 구체 기능, 관련 제품, 적용 사례가 직접 등장하지 않으면 “공개 근거상 직접 확인은 제한적”이라고 표현하고, 산업 수요·제품군 수요·유사 공정 수요를 구분해 평가한다.
- 산업리포트가 대상 특허의 적용 산업과 다르면 근거로 사용하지 않는다.
- 단순히 “시장성이 있음”이라고 쓰지 말고, 어떤 외부 근거가 어떤 시장 신호를 보여주는지 설명한다.
- 외부 근거가 약하면 missing_information에 “공개 근거만으로는 대상 특허의 직접 시장 수요 확인이 제한적임”처럼 표현한다.

# Valuation Market Axis Prompt

시장성 축을 평가한다.

평가 구조:
- 시장성 점수(100) = 산업 시장성(20) + 시장 성장성(20) + 글로벌 사업성(20) + 경쟁성(20) + 발명-시장 연결성(20)
- 당신은 산업 시장성, 글로벌 사업성, 경쟁성, 발명-시장 연결성을 판단한다.
- 시장 성장성은 Input JSON의 `marketability_metrics`에 들어 있는 계산값을 그대로 사용한다.

평가 목적:
- 대상 특허가 속한 외부 산업·시장 환경에서 수요와 성장 가능성이 있는지 평가한다.
- 대상 특허의 핵심 적용 기능이 실제 시장에서 의미 있는 역할을 할 수 있는지 평가한다.
- 동일 적용 분야에서 기존 상용 제품·서비스가 대상 특허의 해결 과제를 얼마나 대체할 수 있는지 평가한다.
- 확인된 시장 수요가 대상 특허의 핵심 적용 기능 및 해결 과제와 얼마나 직접 연결되는지 평가한다.

사용 가능한 근거:
- Vector DB에서 검색된 `industry_report`
- 최근 뉴스 기반 `news` 중 `source`가 `naver_news`(국내특허) 또는 `domestic_news`(해외특허 본국 현지 뉴스)인 대상 특허 본국 뉴스
- `source`가 `global_news`인 해외 뉴스
- Input JSON의 `summary_result`(대상 특허 요약, 핵심 구성, 처리 흐름)
- Input JSON의 `patent.metadata`(`business_area`, `technology_area`, `related_product` 등 대상 특허 기본 정보)
- Input JSON의 `invention_market_linkage_context`(발명-시장 연결성 평가용: `problem_to_solve`, `core_application_functions`, `key_elements`, `expected_effects` 등)
- Input JSON의 `marketability_metrics`

사용하지 말아야 할 근거:
- SK AX 내부 사업, 제품, 포트폴리오, 전략 적합성, 내부 활용 가능성
- 시장 성장성 외 항목에서 CPC/IPC 공개 건수 자체를 직접 시장 수요 근거처럼 사용하는 것
- 확인되지 않은 시장 규모, 성장률, 해외 진출 가능성 추정

공통 평가 원칙:
- `rationale` 등 출력 문구에서 "국내"라는 표현을 쓰지 않는다. 대상 특허가 해외특허이면 "국내"는 한국으로 오인되므로, 본국 현지 근거는 "대상 특허 본국" 또는 해당 국가명(예: 미국, 중국, 일본)으로 지칭한다.
- 대상 특허의 기술분야, 배경기술, 해결하려는 과제, 핵심 적용 기능과 근거가 얼마나 직접 연결되는지 중심으로 판단한다.
- 넓은 AI, 자동화, 디지털 전환, 헬스케어, 제조업 성장 같은 상위 산업 흐름만으로 고득점을 주지 않는다.
- 자료 부족은 실제 시장 약점과 구분한다.
- 자료 부족은 `missing_information`과 `confidence`로 처리하고, 확인되지 않은 약점을 단정하지 않는다.
- 실제 시장 리스크만 `risk_factors`에 넣는다.


----------------------------------------
1. 산업 시장성 (20점)
----------------------------------------

목적:
산업 리포트와 뉴스에서 확인되는 시장 확대, 수요 증가, 성장 전망, 투자 확대, 적용 확산이 대상 특허의 핵심 적용 기능과 직접 연결되는지 평가한다.

점수 기준(수요·성장 근거가 "어느 단위"에서 대상 특허와 연결되는지로 판단한다 — 좁은 단위일수록 고득점):
- 20점: 산업 성장·수요 근거가 확인되고, 그 흐름이 대상 특허의 세부 적용 기능·해결 과제(가장 좁은 단위)와 직접 연결됨
- 13점: 산업 성장·수요 근거가 확인되고, 대상 특허의 적용 분야(제품·서비스 카테고리) 수준에서는 직접 연결되나, 세부 기능 단위까지의 직접성은 부분적임
- 7점: 산업 성장 근거는 확인되나 상위 산업·넓은 기술 분야 수준에 머물러 대상 특허와의 연결성이 약함
- 0점: 산업 성장 근거가 없거나, 확인된 흐름이 대상 특허의 적용 분야와 실질적으로 무관함

작성 규칙:
- 산업 리포트가 있어도 대상 특허의 세부 기능 수요와 연결되지 않으면 20점을 주지 않는다.
- 대상 특허 본국 현지 뉴스(`naver_news`/`domestic_news`)는 최근 적용 확산, 고객 수요, 서비스 출시, PoC, 상용화 움직임을 보조 근거로 사용한다.
- 적용 분야(제품·서비스 카테고리) 수준의 수요·상용화 흐름이 확인되면, 세부 기능 직접성이 약하더라도 7점이 아니라 13점을 우선 검토한다(적용 분야 단위 직접 연결).
- 로보어드바이저, 자동 자산배분, 리밸런싱 같은 적용 분야 수요가 확인되면, 대상 특허의 세부 알고리즘 수요를 직접 입증하지 못하더라도 적용 분야 단위 연결로 보아 7~13점 수준의 근거로 볼 수 있다.
- 0점은 적용 분야 수준의 시장 수요 신호도 거의 없거나, 확인된 흐름이 대상 특허의 적용 분야와 사실상 동떨어진 경우에만 부여한다.
- 단순 일반론 대신 어떤 근거가 어떤 수요 신호를 보여주는지 설명한다.

2. 시장 성장성 (20점)
----------------------------------------

목적:
국내특허는 대표 CPC 기준, 해외특허는 대표 IPC 기준 해당 국가 공개 특허를 사용해 현재 시점에서 18개월 전을 마지막 시점으로 하는 3개 1년 구간의 공개 특허 수 증가율과 추세를 평가한다.

평가 규칙:
- `marketability_metrics.market_growth_score`는 코드 계산값이다.
- 이 값을 변경하지 말고 `subscores.market_growth.score`에 그대로 반영한다.
- `marketability_metrics.market_growth_available`이 false이면 시장 성장성은 산정 불가로 처리한다.
- 산정 불가를 낮은 시장성으로 단정하지 말고 `missing_information`과 `confidence`로 처리한다.
- 분류 전체 성장 흐름은 대상 특허 가치 판단의 보조 정량 지표일 뿐이며, 이것만으로 시장성이 높다고 단정하지 않는다.

점수 구조:
시장 성장성(20) = CAGR 점수(10) + 최근 구간 추세 점수(10)

CAGR 점수:
- 15% 이상: 10
- 8% 이상 15% 미만: 8
- 3% 이상 8% 미만: 6
- 0% 이상 3% 미만: 4
- 0% 미만: 0

최근 3개 구간 추세 점수:
- 최근 3개 구간 공개 특허 수가 연속 증가: 10
- 일부 구간에서 증가: 5
- 최근 3개 구간 공개 특허 수가 연속 감소 또는 증가 흐름이 뚜렷하지 않음: 0

`subscores.market_growth.details`에는 아래 숫자 필드만 넣는다.
- `cagr_score`
- `trend_score`

3. 글로벌 사업성 (20점)
----------------------------------------

목적:
해외 뉴스 기사와 산업 리포트에서 확인되는 해외 시장 확대, 수요 증가, 제품화, 서비스 확산, 고객 도입, 규제 변화가 대상 특허의 핵심 기능과 직접 연결되는지 평가한다.

점수 기준(수요·성장 근거가 "어느 단위"에서 대상 특허와 연결되는지로 판단한다 — 좁은 단위일수록 고득점):
- 20점: 해외 시장 성장·수요 근거가 확인되고, 그 흐름이 대상 특허의 세부 적용 기능·해결 과제(가장 좁은 단위)와 직접 연결됨
- 13점: 해외 시장 성장·수요 근거가 확인되고, 대상 특허의 적용 분야(제품·서비스 카테고리) 수준에서는 직접 연결되나, 세부 기능 단위까지의 직접성은 부분적임
- 7점: 해외 시장 성장 근거는 확인되나 상위 산업·넓은 기술 분야 수준에 머물러 대상 특허와의 연결성이 약함
- 0점: 해외 시장 성장 근거가 없거나, 확인된 흐름이 대상 특허와 실질적으로 무관함

작성 규칙:
- `source`가 `global_news`인 해외 뉴스는 산업 시장성이 아니라 글로벌 사업성 근거로 우선 사용한다.
- 해외특허의 경우 자국 기사라도 해당 국가를 제외한 해외 시장의 진출, 도입, 활용, 확산 흐름이 확인되면 글로벌 사업성 근거로 사용할 수 있다.
- 넓은 AI, 자동화, 디지털 전환 흐름만 있고 대상 특허의 핵심 기능과 직접 연결되지 않으면 긍정 근거로 사용하지 않는다.
- 글로벌 근거 부족을 감점 사유처럼 길게 설명하지 않는다.


----------------------------------------
4. 경쟁성 (20점)
----------------------------------------

목적:
동일 적용 분야에서 대상 특허의 적용 기능과 해결하려는 과제를 대체할 수 있는 기존 상용 제품·서비스의 존재와 대체 압력을 평가한다.

점수 기준:
- 20점: 동일 적용 분야에서 대상 특허의 적용 기능과 해결 과제를 대체할 만한 상용 제품·서비스 후보가 충분한 검색 후에도 거의 확인되지 않음
- 13점: 유사 상용 제품·서비스 후보는 확인되지만, 인접 기능·부분 기능·제한적 적용 수준에 머물러 충분한 대체가 어려움
- 7점: 유사 후보는 있으나 기사 내용만으로 실제 운영 여부, 제공 기능, 적용 범위, 대체 가능성을 판단하기 어려움
- 0점: 기존 상용 제품·서비스가 다수 존재하고 실제 운영·도입 사례가 확인되며 대상 특허의 해결 과제를 상당 부분 대체 가능함

작성 규칙:
- 경쟁성은 상용 제품·서비스의 대체 압력을 보는 항목이다.
- 단순 특허 공개 건수, 일반 시장 경쟁 심화, 추상적 경쟁 우려는 경쟁성 근거가 아니다.
- 기존 제품이 존재하더라도 기능 범위와 해결 과제 대응 수준이 제한적이면 13점 또는 7점을 검토한다.
- "로보어드바이저", "자동화 서비스", "AI 솔루션"처럼 상위 서비스 범주의 존재만으로는 0점을 줄 수 없다.
- 0점은 대상 특허의 핵심 적용 기능 또는 해결 과제가 기존 상용 제품·서비스에서 실제 운영 수준으로 상당 부분 구현된 근거가 확인될 때만 부여한다.
- 상용 제품의 존재는 확인되지만 세부 기능 대체 여부가 기사만으로 명확하지 않으면 기본적으로 7점 또는 13점을 우선 검토한다.
- 자료가 부족한데도 단정적으로 0점을 주지 않는다.

----------------------------------------
5. 발명-시장 연결성 (20점)
----------------------------------------

목적:
대상 특허의 기술분야, 배경기술, 해결하려는 과제, 핵심 적용 기능이 실제 시장 수요, 기업 도입 목적, 제품·서비스 적용 방향, 고객 문제와 얼마나 직접 연결되는지 평가한다.

점수 기준:
- 20점: 대상 특허의 핵심 적용 기능과 해결 과제가 실제 시장 수요, 기업 도입 목적, 제품·서비스 적용 방향과 직접 연결됨
- 13점: 대상 특허의 핵심 적용 기능이 시장 수요와 일부 연결되지만, 확인된 근거가 세부 기능보다는 적용 분야 또는 유사 문제 수준에 머무름
- 7점: 대상 특허가 속한 산업 또는 기술 분야의 시장 수요는 확인되지만, 대상 특허의 구체적 해결 과제와 직접 연결되는 근거가 부족함
- 0점: 확인된 시장 수요가 대상 특허의 해결 과제와 실질적으로 연결되지 않거나, 대상 특허의 핵심 기능이 실제 시장 문제 해결에 필요한 기능이라고 보기 어려움

작성 규칙:
- 이 항목은 산업 시장성과 다르다. 산업 시장성은 외부 시장 확대 여부, 발명-시장 연결성은 그 수요가 대상 특허의 구체적 해결 과제와 직접 맞물리는지를 본다.
- `invention_market_linkage_context`의 `problem_to_solve`, `core_application_functions`, `key_elements`, `expected_effects`를 우선 참고한다.
- 상위 산업 수요만 확인되고 특허의 구체 기능 연결이 약하면 7점 또는 13점을 검토한다.
- 내부 사업 적합성, SK AX 포트폴리오, 자사 전략 활용 가능성은 근거로 사용하지 않는다.


----------------------------------------
종합 점수 산정
----------------------------------------

score = 산업 시장성 + 시장 성장성 + 글로벌 사업성 + 경쟁성 + 발명-시장 연결성

`score`는 아래 합으로 작성한다.
- `subscores.industry_marketability.score`
- `subscores.market_growth.score`
- `subscores.global_business.score`
- `subscores.competitiveness.score`
- `subscores.invention_market_linkage.score`

단, `subscores.market_growth.score`가 null이면 산정 가능한 점수만 합산하고 confidence를 낮춘다.

출력 규칙:
- `subscores.industry_marketability.score`는 0, 7, 13, 20 중 하나로 작성한다.
- `subscores.global_business.score`는 0, 7, 13, 20 중 하나로 작성한다.
- `subscores.competitiveness.score`는 0, 7, 13, 20 중 하나로 작성한다.
- `subscores.invention_market_linkage.score`는 0, 7, 13, 20 중 하나로 작성한다.
- `subscores.market_growth.score`는 입력 계산값을 그대로 사용한다.
- `subscores.market_growth.details`에는 세부점수만 넣고 설명 문장은 넣지 않는다.
- 점수 감점 사유와 자료 부족 사유를 구분한다.
- 실제 시장 리스크만 `risk_factors`에 작성한다.

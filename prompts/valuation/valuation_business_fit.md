# Valuation Business Fit Axis Prompt

사업 연계성 축을 평가한다.

평가 목표:
- 대상 특허가 회사의 사업, 제품, 서비스, 기술 영역과 얼마나 연결될 가능성이 있는지 평가한다.
- 실제 제품 적용 여부나 사업 적용 여부는 입력 근거가 있을 때만 언급한다.
- 입력 근거가 부족하면 메타데이터 기반의 임시 평가로 처리한다.

사용 근거 우선순위:
1. 회사명과 관련 기술/제품/서비스가 함께 등장하는 뉴스 또는 공식 자료
2. 특허명, 기술명, 제품명, 서비스명이 직접 등장하는 뉴스 또는 공식 자료
3. 회사 공시, 사업보고서, 공식 홈페이지, 보도자료
4. 사업부 의견, 체크리스트, 내부 문서
5. portfolio_context
6. related_product, business_area, technology_area 메타데이터

평가 기준:
- 높은 점수: 회사명과 관련 기술/제품/서비스가 함께 등장하는 직접 근거가 있고, 특허 기술과 사업 영역의 연결이 명확한 경우
- 중간 점수: 직접 적용 근거는 없지만 related_product, business_area, technology_area, portfolio_context상 회사 사업 영역과 연결 가능성이 있는 경우
- 낮은 점수: 사업 관련 근거가 거의 없거나, 기술 영역과 회사 사업 영역의 연결이 약한 경우

주의:
- 제품명이 있다는 이유만으로 실제 적용 중이라고 단정하지 않는다.
- related_product가 있으면 “관련 제품 후보”로만 표현하고, 실제 적용 제품으로 단정하지 않는다.
- portfolio_context는 보완 근거로만 사용하고, 단독으로 높은 점수를 부여하지 않는다.
- sibling 특허들이 회사의 동일 제품/공정/서비스에서 서로 다른 기능을 보호하는 경우 사업 포트폴리오 연결 가능성의 보조 근거로 반영한다.
- 단일 특허보다 특허군으로 묶였을 때 제품/공정 보호 범위가 넓어지는지 판단하되, 실제 적용 여부는 별도 직접 근거가 있을 때만 언급한다.
- 회사의 내부 적용 여부가 뉴스나 공개 자료에 나오지 않는 것은 자연스러우므로, 공개 근거 부재를 “사업 연계성 낮음”으로 바로 해석하지 않는다.
- 공개 근거가 없으면 “공개 자료상 직접 적용 여부는 확인되지 않음”으로 표현하고, related_product, business_area, technology_area, 유사·보완 특허군을 근거로 연결 가능성을 별도 판단한다.
